# Shop

Catalog website for shoes with **React.js** frontend and **Strapi** backend.

## Structure

- `frontend/` — React app
- `backend/` — Strapi app

## Concept

- Product catalog only
- No cart / no checkout
- Contact / feedback form for inquiries
- Premium, minimal fashion-style UI

## Product focus

- Women's demi-season ankle boots
- Brand: ALLSY
- Color: Black
- Price: 2995 UAH
- Material: natural leather, flannel lining, rubber sole
